Invisible units
===============

Author: Aewsomn
Version: 1.0
Target: Mindustry v8 build 159.7+

What it does
------------
Adds a setting named "Invisible units". When enabled, the Mono, Poly, and Mega unit sprites become fully transparent. The mod also suppresses their body visual parts, cell/item visuals, shadows, and animated visual parts so the wings cannot remain visible.

The units remain fully functional: movement, mining/building/repairing, weapons, stats, health, collision and AI are unchanged.

Usage
-----
1. Import Invisible-units-1.0.zip through Mindustry's Mods dialog.
2. Restart once when Mindustry requests it after importing.
3. Open Settings -> Invisible units.
4. Toggle the checkbox. Changes apply immediately.

The ZIP is a standard Mindustry mod package and can be uploaded directly to a Discord channel as a file.
